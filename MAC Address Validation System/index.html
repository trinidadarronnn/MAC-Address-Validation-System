MAC Address Validator

A DFA-based lexical analyzer that checks whether a MAC address follows the format 00:1A:2B:3C:4D:5E: six pairs of hexadecimal characters separated by colons, 17 characters in total. The input is read one character at a time and the DFA moves from state to state until it accepts or rejects.

DFA Visualization

q0 is the start state, q17 (double circle) is the accepting state, and qd is the trap state. "hex" means one of 0-9 A-F a-f. Any other character, from any state, goes to qd. The current state is highlighted while the input is processed.

Validation Process

  1. Enter a MAC address.
  2. Read each character from left to right.
  3. Check whether each character matches the expected hexadecimal character or colon.
  4. Reach q17 if all 17 characters are valid.
  5. Display ACCEPTED or NOT ACCEPTED.
